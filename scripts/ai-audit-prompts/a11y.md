# Accessibility + UX lens — prompt template

You are running the **a11y / UX lens** of a multi-lens audit on a
React 19 + Next 16 static-export project. `eslint-plugin-jsx-a11y`
(recommended ruleset) is already active and catches the basics;
your job is to find what that ruleset misses.

## Scope

- `src/components/*.tsx` (primary)
- `src/app/*.tsx` (page / layout)
- `src/hooks/useFocusTrap.ts`
- `src/contexts/*.tsx` (any provider that renders UI)

## What to look for

- **Keyboard navigation gaps** — a feature reachable only by click,
  missing tab stop, non-logical tab order.
- **Focus management** — focus lost on dialog close, focus not
  restored, autofocus on the wrong element.
- **ARIA correctness** — `aria-*` referring to non-existent IDs,
  role mismatch, `aria-hidden` on a focusable element.
- **Affordances conveyed only by color** — hover-only states,
  poor contrast.
- **`prefers-reduced-motion` / `prefers-color-scheme` respected?**
  animations that ignore the OS-level signal.
- **Screen-reader announcements** — state changes (save, copy,
  error) not announced; landmark regions missing.
- **Touch targets** — interactive element < 44 px on mobile.
- **i18n** — hardcoded English in a project that supports Korean
  content; date / number formatting that ignores locale.
- **WCAG 2.5.3 Label-in-Name** — visible label and accessible name
  must match in the visible substring.

## Hard rules

- Every finding **must** quote the exact JSX line.
- Verify the line exists with `Read` — do not assume.
- Do **not** report things `eslint-plugin-jsx-a11y/recommended`
  already catches (img-alt, label-for, redundant-role,
  button-has-content, etc.).
- Do **not** report speculative SR behaviour you cannot infer from
  the code.
- Read `AGENTS.md` § 4 before reporting.

## Output schema

Return ONLY a JSON array, max 10 findings:

```json
[
  {
    "file": "src/components/Foo.tsx",
    "line": 42,
    "severity": "real-bug" | "cleanup" | "nit",
    "category": "keyboard-nav" | "focus-mgmt" | "aria" | "contrast" | "motion" | "sr" | "touch" | "i18n",
    "evidence": "exact quoted JSX (<= 120 chars)",
    "rationale": "what user is impacted and how (<= 200 chars)",
    "suggested_patch": "concrete code change (<= 200 chars)"
  }
]
```

Empty array `[]` if nothing survives.
